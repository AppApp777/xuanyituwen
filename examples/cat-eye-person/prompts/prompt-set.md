# 《猫眼里面的人》实际生图 prompt 集

七张底图均使用内置 `image_gen`，一张图一次调用。所有 prompt 均要求纯净无字底图；抖音发布页配文由创作者填写，当前流程不做图片内嵌字。

## 固定 prompt 结构

每张 prompt 均按以下结构组装：

1. 全局真实记录基底。
2. 本张记录载体。
3. 角色、门体、猫眼、门链和检修腔连续性锁定。
4. `spatial-anchor-ledger.md` 中的空间锚点合同，原样带入每张 prompt。
5. 本张的单一视觉证据。
6. 光源、方向和空间关系。
7. 本张状态变化。
8. 基础负面约束。

第七张额外加入终局惊吓段，要求脸距离镜头不到十厘米、占据画面主体，并保留门体空间证明；即使跳脸，也不能牺牲 `ANCHOR-01` 至 `ANCHOR-06` 的父面和局部拓扑关系。

## 文件

- `frame-01.txt`：固定时间的敲门声。
- `frame-02.txt`：门外没人。
- `frame-03.txt`：雾气在内侧。
- `frame-04.txt`：敲击来自门内。
- `frame-05.txt`：猫眼后有空腔。
- `frame-06.txt`：里面有人。
- `frame-07.txt`：猫眼里面的人，近距离 jump scare。
