# 伪记录悬疑图文验收门

按顺序检查。前面的故事门没有通过时，不要用画面质量掩盖问题。

## 检查记录格式

每个检查项都尽量记录下面字段。它们是验收证据，不是每次生成时都要写进 prompt 的额外长文本：

```yaml
severity: hard | major | minor
result: pass | fail | not-applicable
evidence: <文件路径、FRAME ID、EVID ID 或人工观察>
reviewer: <人或模型>
artifact: <被检查的图片或文档>
fix_target: <失败时回到哪个阶段>
```

## 一、故事逻辑门

- [ ] 作者真相或不可解释规则明确。
- [ ] 每张图都带来新事实、状态变化、判断变化或新问题。
- [ ] 角色的行动由已有证据和动机推动，而不是为了让剧情继续而硬走。
- [ ] 记录者只知道自己能观察到的内容。
- [ ] 结尾的后果改变了局面，而不是停在一句模糊台词上。

## 二、伏笔与反转门

- [ ] 至少三条核心线索在前文出现，并注册为 `CLUE-*`。
- [ ] 至少两处前文细节在最后重新获得解释，并引用具体 `EVID-*`。
- [ ] 误导线索有事实依据，不是作者故意欺骗。
- [ ] 最后一张没有凭空增加决定性的新身份、新能力或新证据。
- [ ] 第一次阅读有悬念，回看时能发现线索。

## 三、连续性门

- [ ] 时间顺序成立，角色能到达下一张的地点。
- [ ] 角色知道的内容没有越界。
- [ ] 角色脸、发型、年龄感、衣着和主要动作连续。
- [ ] 场景结构、光线方向和关键物件位置连续。
- [ ] 每个 `ANCHOR-*` 的父面、局部拓扑、朝向、尺度和状态连续。
- [ ] 没有出现物件换父面、镜像、上下顺序改变、相邻距离突变、重复物件或无理由漂移。
- [ ] 只有同镜位或可比较镜位才比较图像平面坐标。
- [ ] 每张实际 prompt 都包含同一版空间拓扑合同；失败图没有被当成新参考图。
- [ ] 记录来源的切换有时间、来源和观看权限依据。

## 四、纯净画面门

- [ ] 每张最终图是 9∶16，默认 1080×1920。
- [ ] 画面没有平台水印、头像、用户名、点赞、评论、标题、分享按钮或生图模型残留文字。
- [ ] 关键人物和决定性线索没有被后期元素遮挡。
- [ ] 画面不依赖图片内文字才能理解基本事件推进。
- [ ] `base/` 与 `final/` 都保持纯净无字，最终 PNG 为 RGB。
- [ ] 归一化结果只声明 `text_layer_added: false` 和 `ocr_check: not_run`，没有把未运行 OCR 写成已通过检查。

## 五、终局图冲击力门

终局图必须同时通过故事门和视觉门。默认目标是让观众在缩略图状态下先看见主体，再理解线索；如果故事需要延迟识别，必须在逐图卡里记录例外理由。没有输入图片时，不得声称“已通过视觉验收”。

`subject_bbox` 统一使用归一化 `[x, y, width, height]`，`thumbnail` 默认固定为 270×480。完整交付包把这组结果写入 `manifest.json`，校验器只检查字段、范围和阈值，不代替人工判断主体是否真的醒目。

- [ ] `subject_bbox` 已标出，主体占画面主要区域，默认约 60％～80％。
- [ ] 固定缩略图规格后，主体身份、动作或威胁仍然可识别。
- [ ] `focal_count` 为 1，背景、道具和光源都服务于主体，不争夺注意力。
- [ ] 主体轮廓、明暗关系和关键颜色足够清楚，不能依赖配文才知道画面在吓什么。
- [ ] 终局冲击来自已经建立的对象、距离、盲区、反光、遮挡或方向，不靠突然堆入无依据的新怪物。
- [ ] 未通过时只针对主体比例、焦点、对比或背景干扰修正，不把失败画面当作新的连续性参考。

终局图记录示例：

```yaml
severity: major
result: pass
evidence: FRAME-07，final/frame-07.png，subject_bbox=[0.12, 0.06, 0.76, 0.82]
reviewer: human-1
artifact: final/frame-07.png
fix_target: frame-card
```

## 六、结尾门

- [ ] 最后一张比前一张明显改变观感。
- [ ] 恐怖或悬疑落点与前面线索有关。
- [ ] 反转后至少两处旧细节变得更可怕或更不可靠。
- [ ] 最后一张留下新的现实后果或无法轻易摆脱的问题。
